# 08 — Active Response (Part 6)

Active Response can execute an action when a configured alert condition is met. It is powerful and can disrupt systems or connectivity.

## Safety requirements
- Test only on a disposable or dedicated lab endpoint.
- Understand exactly what the response command changes.
- Start with a harmless test action where possible.
- Keep a recovery path and console access.
- Never enable untested response actions in production.
