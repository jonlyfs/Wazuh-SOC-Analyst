## Analysis workflow
1. State the question you are trying to answer.
2. Define the time window and endpoint.
3. Search for the relevant event or alert.
4. Inspect timestamps, user/process/parent process, source, destination, and other relevant fields when available.
5. Correlate related events into a timeline.
6. Explain what is known, what is uncertain, and what additional evidence is needed.

Do not upload raw logs containing personal or sensitive information.
