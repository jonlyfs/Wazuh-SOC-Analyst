# 02 — Wazuh 101

## What Wazuh does
Wazuh is an open-source security platform used for security monitoring, threat detection, configuration assessment, and response. In this lab, focus on the relationship between the endpoint agent, Wazuh server/manager, indexer, and dashboard.

## Core concepts to document
- **Agent:** collects endpoint data and forwards it to the server.
- **Manager:** receives and analyzes events, applies decoders/rules, and manages agents.
- **Indexer:** stores and indexes data for searching and visualization.
- **Dashboard:** interface for exploring alerts, agent health, and security data.
- **Rules and decoders:** interpret events and generate alerts.
- **FIM:** monitors selected files and directories for changes.
